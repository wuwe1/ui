# 命名和界面文字

## 命名

- 标识符一律英文原名，不翻译：组件（`Inbox`、`ApprovalCard`、`Tray`）、变量、token（`muted-foreground`）、文件名、文档小节名（When to use、Notes for AI）、术语（live region、roving tabindex）
- 自己新起的组件、功能也直接用名字：叫 `Inbox`，不叫「任务总览」；讨论、文档、提交信息里都这么写
- 给人理解的说明用中文：注释、文档正文、提交信息、界面上的字
- 文件名 kebab-case（`status-icon.tsx`），组件名 PascalCase（`StatusIcon`），一个文件一个主组件，文件名就是 `@wuwe1/ui/<文件名>`
- token 的名字说用途（`muted-foreground`、`waiting-strong`），不说颜色（不叫 `gray-500`、`amber`）

## 界面文字

书面、简洁、中性，像系统界面不像聊天（能不能出现在 macOS 的中文系统设置里）。

- 不用口语动词：跑 → 运行、画 → 生成 / 显示、看 → 查看、停掉 → 停止、关掉 → 关闭、去掉 → 移除、算了 → 取消、建 → 创建
- 不写「没 X」「不对」「不认识」，写「X 失败」「无效」「未知」
- 出错：动作失败「X 失败：原因」；被拦下「原因：怎么办」；说不出原因「未知错误」
- 状态四种写法：「已 X」（已完成、已暂停）、「X 中」（短标签：运行中）/「正在 X…」（行内）、「待 X」（待确认）、「X 失败」
- 空状态：「X 为空」或「暂无 X」，下面一句说这里会出现什么
- 按钮 2–6 字、动词开头，要再填一句的带「…」（「拒绝…」），取消一律「取消」；状态不超过 8 字；tooltip 一句、不用「；」；说明不超过两句（一句不加句号，两句以上都加）
- 几样信息排在一行不用「·」「|」隔开（中文里「·」是外国人名的间隔号）：主次靠位置（次要的靠右）、颜色、字重分，上下级用「›」（「仓库 › worktree」）
- 人称「你」，不用「您」「请」；用「这一轮」「这个会话」，不用「本轮」「此」
- 省略号只用「…」；界面元素名用「」；数字和单位之间空格（14 MB），百分号紧贴；「万」一位小数；点击说「点」
